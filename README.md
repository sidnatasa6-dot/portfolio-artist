Портфоліо художника. Вебсайт-галерея з каталогом картин, інформацією про автора, виставки та формою замовлення робіт.

- CSS3
- JavaScript


## Лабораторна робота № 5: CSS Grid Дашборд
- Створено адаптивну сторінку аналітичної панелі (`dashboard.html`, `dashboard.css`).
- Використано двовимірну розкладку CSS Grid (`grid-template-areas`, `fr`, `repeat()`, `minmax()`, `auto-fit`, `span 2`, `grid-auto-flow: dense`) та вкладену Grid-діаграму.


## Лабораторна робота № 6: Основи JavaScript
- Створено сторінку конвертера величин та каталогу художніх товарів (`lab6.html`, `lab6.js`).
- Величина конвертера за варіантом № 8 — **площа** (`см²`, `м²`, `фут²`, `акр`, `га`, `км²`).
- Результати 5 тестів валідації `parseValue`: `"5,5"` → `{ number: 5.5 }`, `""` → `{ error: "Введіть значення." }`, `"abc"` → `{ error: "Введіть коректне число..." }`, `"-3"` → `{ error: "Значення не може бути від'ємним." }`, `" 12 "` → `{ number: 12 }`.
- Поверхневе копіювання `catalog.slice()` перед `.sort()` створює копію масиву, щоб не змінювати (не мутувати) вихідний масив `catalog` і зберегти початковий порядок товарів для кнопки «Усі».
