## Інтеграція бази даних MongoDB (ЛР № 12)

У межах лабораторної роботи № 12 серверну частину (`lr11-server/`) підключено до хмарної бази даних **MongoDB Atlas** за допомогою ODM-бібліотеки **Mongoose**.

### Налаштування середовища
1. Скопіюйте файл шаблону `lr11-server/.env.example` у `lr11-server/.env`:
   ```bash
   cp lr11-server/.env.example lr11-server/.env
   ```
2. Заповніть у файлі `.env` змінні середовища:
   - `PORT` — порт запуску HTTP-сервера (за замовчуванням `3008`).
   - `MONGODB_URI` — рядок підключення до кластера MongoDB Atlas із назвою бази `lr12`.

### Команди запуску
Перейдіть у каталог сервера (`cd lr11-server`) та використовуйте:
- `npm run seed` — очищення колекції `paintings` та початкове наповнення 5 тестовими записами.
- `npm run dev` — запуск сервера в режимі розробки з автоматичним перезапуском.
- `npm start` — запуск сервера у звичайному режимі.

### Маршрути API (`/api/paintings`)
- `GET /api/paintings` — отримання списку робіт (підтримує пошук за назвою `?q=` та обмеження кількості `?limit=`).
- `GET /api/paintings/:id` — отримання однієї роботи за ідентифікатором `ObjectId`.
- `POST /api/paintings` — створення нового запису з валідацією полів (`title`, `style`, `year`).

## Лабораторна робота № 13. REST API: картини (Художник)

Базова адреса: `/api/paintings`

| Метод | Адреса | Дія | Успіх | Помилки |
| :--- | :--- | :--- | :--- | :--- |
| GET | `/api/paintings` | Список записів (`?q`, `?style`, `?sort`, `?page`, `?limit`) | 200 | 400 |
| GET | `/api/paintings/:id` | Отримання одного запису за id | 200 | 400, 404 |
| POST | `/api/paintings` | Створення нового запису | 201 | 400, 409, 413 |
| PUT | `/api/paintings/:id` | Повна заміна запису за id | 200 | 400, 404, 409, 413 |
| PATCH | `/api/paintings/:id` | Часткова зміна переданих полів запису | 200 | 400, 404, 409, 413 |
| DELETE | `/api/paintings/:id` | Видалення запису за id | 204 | 400, 404 |

- **Параметри списку (`GET /api/paintings`):** `q` (пошук за назвою `title`), `style` (фільтр за стилем), `sort` (`title`, `year`, `createdAt`; префікс `-` — за спаданням), `page` (номер сторінки), `limit` (1–100).
- **Загальна кількість записів за фільтром:** передається у заголовку відповіді `X-Total-Count`.
- **Формат помилок:** `{ "error": "Повідомлення", "details": ["..."] }`.
- **Команди:** `npm install`, `npm run seed`, `npm run dev`, автоматична перевірка: `npm run check`.
